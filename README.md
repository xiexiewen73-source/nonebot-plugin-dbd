# NoneBot-Plugin-DBD-Map

一款基于 [NoneBot2](https://v2.nonebot.dev/) 框架的《黎明杀机》官方地图平面图插件。支持中英文双关键词查询，并可自定义别名，提供快速、精准的地图信息检索服务。

## ✨ 功能特性
- **全面覆盖**：内置《黎明杀机》全部主要地图的权威平面图。
- **双语检索**：支持官方英文原名与中文译名一键查询。
- **动态扩展**：支持通过指令添加自定义别名，无需修改源码或重启机器人。
- **智能防抢**：针对群聊复杂环境，提供高优先级响应，避免被其他插件误拦截。
- **实时监控**：在查询遭遇异常时，自动将报错信息私聊通知管理员。

## 📦 安装

**方式一：通过 NoneBot CLI 安装（推荐）**
在项目根目录下运行：
```bash
nb plugin install nonebot-plugin-dbd-map
```
**方式二：通过 pip 安装**
```bash
pip install nonebot-plugin-dbd-map
```
## 🎮 使用说明

### 指令一览

| 指令 | 说明 | 示例 |
| :--- | :--- | :--- |
| `/查询 [关键词]` | 根据关键词检索地图并发送图片 | `/查询 阿扎罗夫` |
| `/地图 [关键词]` | 同 `/查询`，简写形式 | `/地图 天堂加油站` |
| `/添加别名 [原关键词] [新别名]` | 为地图添加自定义别名 | `/添加别名 阿扎罗夫 阿扎` |

### 触发规则

- 群聊中：需 `@机器人` 并附带指令内容。
- 私聊中：直接发送指令内容即可。

### ⚙️ 配置说明

**静态资源目录**

插件需要读取地图图片进行展示。请在项目根目录下创建 `static/DBD_Map/` 文件夹，将所有地图图片放入该文件夹中，并以官方英文名命名（如 `azarovs_resting_place.jpg`）。若图片放置在其他位置，请自行调整代码中的路径拼接逻辑。

**超级管理员（可选）**

若需开启错误自动上报功能，请在 `.env` 文件中配置：

```ini
SUPERUSERS=["你的QQ号"]
```

### 🐛 常见问题（FAQ）

**Q1：查询时提示“图片发送失败”是什么原因？**
A：通常是图片路径配置错误，或图片文件名与代码中的 `BASE_MAP_DATA` 字典不完全匹配。请检查 `static/DBD_Map/` 文件夹下的文件是否正确。

**Q2：添加别名后，为什么提示“找不到原关键词”？**
A：请确认原关键词是插件内置的官方中文名或英文名，而不是你自己上一次添加的别名。

**Q3：插件被其他群聊插件抢占了响应？**
A：本项目已内置高优先级拦截机制，如仍遇到拦截，请检查 `nonebot` 全局配置中的 `priority` 设置。
